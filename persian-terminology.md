# 📘 Persian Terminology Reference – «کی‌داد؟ / WhoPaid?»

This document defines all Persian (Farsi) terminology, UX copy, and domain language
used in the **WhoPaid? (کی‌داد؟)** application.

Purpose:
- Maintain consistent Persian language across UI, UX, AI responses, and notifications
- Avoid formal, bureaucratic, or judgmental tone
- Match Iranian cultural and conversational norms

## 2. User Financial State (وضعیت مالی کاربر)

| Situation | Persian Copy |
|---------|-------------|
| User owes money | بدهکار هستی |
| User is owed money | طلبکاری |
| Balance is zero | حسابت صافه |
| Pending settlement | در انتظار تسویه |
| Settled | تسویه شد |
| Not settled | تسویه نشده |

✅ Preferred:
- بدهکاری / طلبکاری  
❌ Avoid:
- کاربر بدهکار است

## 11. Forbidden Language (لحن ممنوع)

❌ Formal / bureaucratic:
- کاربر
- بدهکار می‌باشد
- تراکنش مالی

❌ Judgmental:
- هنوز پول ندادی
- باید پرداخت کنی

---

## 12. Voice & Tone Principle

> Friendly, clear, neutral  
> Designed to prevent arguments 😄

---

## 13. Product Philosophy

If the user cannot understand:
- how much they owe,
- to whom,
- and why,

within **5 seconds**, the UX is considered broken.
